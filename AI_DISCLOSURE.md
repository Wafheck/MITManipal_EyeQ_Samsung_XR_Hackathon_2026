# AI Assistance

The rig, scene, and base wrapper are the team's own work.

AI was used for part of the final stage of development.

- **Wrapper additions and polishing:** Eyelid shape keys and video generation were done with help and suggestions from AI.
- **Helper script:** A standalone contact-sheet generator for testing various aspects.
- **Docs and review:** Editing the README and performing sanity checks.

All AI-assisted code was run and tested by the team.
